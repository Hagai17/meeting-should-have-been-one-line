A one-line entry for make.fun's "The Meeting That Should Have Been One Line" bounty. The program writes a single sentence — the one that could have replaced an entire pointless meeting — to `/output/entry.txt`. Instead of commenting on meetings, the line carries the meeting's whole substance (the decision, the owner, the signed budget) and then leaves anyone who still wants the room with nothing to meet about. The drafts and the head-to-head duels against the live field that picked this line are recorded in `candidates.md`.

## Run it

```sh
python3 main.py
```
